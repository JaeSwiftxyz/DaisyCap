# Keyboard sounds

Both packs are **CC0 1.0 (public domain)**, so no attribution is required in
the app. They were taken from the [clatterbox](https://github.com/zordhalo/clatterbox)
project (its code is Apache-2.0; its bundled audio is CC0), which documents
each source file and its licence.

Files here were resampled to 48 kHz mono 16-bit WAV with `afconvert`.

## office/ — a muted office keyboard

Recorded by **unicaegames** (Cherry KC 1000 through a Shure SM7B), from
"Keyboard Soundpack 1 — Typing and Single Keystrokes" on OpenGameArt, CC0:
<https://opengameart.org/content/keyboard-soundpack-1-typing-and-single-keystrokes>

16 of the pack's single-key recordings, renamed `down-01..16.wav`.

## tactile/ — a tactile mechanical keyboard

Recorded by **StavSounds**, **Foxfire-**, **alpinemesh** and **yottasounds**,
from Freesound; each file's page was checked as CC0. The pack's own CREDITS
lists the individual sources, for example
<https://freesound.org/people/StavSounds/sounds/766628/>.

`down-01..12.wav`, plus `enter-down-01.wav` and `backspace-down-01.wav`.
